# The SADA Protocol (DAS)

**The SADA Protocol (DAS)** is an advanced AI Agent designed to function as a personal financial advisor. It combines the analytical power of large language models with real-time financial data to provide actionable insights, portfolio management, and financial planning.

## 🚀 Key Features

- **Market Analysis**: Real-time tracking of stocks, crypto, and indices.
- **Portfolio Management**: Analysis of user holdings, risk assessment, and rebalancing recommendations.
- **Financial Planning**: Budgeting, retirement planning, and savings goals.
- **Intelligent Chat**: A conversational interface to discuss financial strategies and news.

## 🏁 Getting Started

### Prerequisites

- Node.js & npm
- Python 3.8+

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/epochon/The-SADA-Protocol.git
    cd The-SADA-Protocol
    ```

2.  **Frontend Setup:**
    ```bash
    cd frontend
    npm install
    npm run dev
    ```

3.  **Backend Setup:**
    ```bash
    cd backend
    python -m venv venv
    .\venv\Scripts\activate
    pip install -r requirements.txt
    uvicorn app.main:app --reload
    ```
